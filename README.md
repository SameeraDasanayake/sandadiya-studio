- එක tap එකකින් දාන්න පුළුවන් ලස්සන ස්ටයිල්, highlight වචන, අලංකාර ඉරි, watermark
- 2K export එකක් හදලා කෙලින්ම Facebook එකට share කරන්න පුළුවන්
- 🎬 **Video mode**: typewriter, fade, blur, pop වගේ text animations 9ක්, මල් පෙති / වැස්ස / හදවත් / තරු වගේ effects, ෆොටෝ හරි video clip හරි background එකට, HD MP4 export
- 😍 **Stickers & Emoji**: vector stickers 16ක්, emoji 100+ක්, text stickers. ඇදලා, ලොකු කරලා, කරකවන්න පුළුවන්. Video එකේදී animate වෙනවා
- 🎵 **Music**: තමන්ගේ සින්දුවක් (waveform එකෙන් කොටස තෝරන්න පුළුවන්), app එකම හදන copyright-free piano / ambient / වැස්ස / මුහුදු රළ සද්ද, typewriter සද්දය, video clip එකේ සද්දය
- **Offline** වැඩ කරනවා. ෆොටෝස් කිසිම server එකකට යන්නේ නෑ, ඔක්කොම device එක ඇතුලෙමයි.

## Install කරන්නේ කොහොමද
Android Chrome එකෙන් site එක open කරලා **⋮ → Add to Home screen / Install app** ඔබන්න.

MP4 හදන්නේ [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) (MIT) එකෙන්.
